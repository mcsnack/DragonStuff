# DragonStuff Resource Pack 26.3

**Ein Minecraft Java Resource Pack für die DragonStuff-Gegenstände – passend zum DragonStuff-Paper-Plugin.**

DragonStuff setzt auf einen dunklen, dracheninspirierten Stil mit violetten Akzenten. Für diese Ausgabe werden die Grafiken als **eigenständige Pixel-Art-Designs** neu erstellt. Das Pack ist für **Minecraft Java Edition 26.3** vorgesehen.

> **Projektstatus:** Die vollständige Neugestaltung der Texturen ist noch in Arbeit. Bis alle bisherigen Grafiken ersetzt sind, können für einzelne Dateien weiterhin Rechte und Lizenzbedingungen Dritter gelten.

## Inhalt

Das Resource Pack enthält beziehungsweise erhält eigene Darstellungen für:

- **Waffen:** Dragon Sword
- **Werkzeuge:** Dragon Pickaxe, Dragon Axe, Dragon Shovel und Dragon Hoe
- **Rüstung:** Dragon Helmet, Dragon Chestplate, Dragon Leggings und Dragon Boots – einschließlich der Darstellung am Spieler
- **Flügel:** Dragon Wings (Elytra)
- **Schmiedematerial:** Dragon-Trim-Icon

## Installation

1. Lade die Datei `DragonStuff_Resource_Pack_26.3.zip` herunter.
2. Starte Minecraft Java Edition **26.3**.
3. Öffne **Optionen → Ressourcenpakete → Paketordner öffnen**.
4. Kopiere die ZIP-Datei unverändert in den Ordner `resourcepacks`.
5. Aktiviere **DragonStuff Resource Pack 26.3**.
6. Spiele auf einem Server mit einer kompatiblen Version des **DragonStuff-Plugins**.

**Hinweis:** Das Resource Pack verändert ausschließlich die Darstellung. Neue Items, Eigenschaften und Schmiederezepte stellt das Plugin bereit.

## DragonBackPack-Farbmodelle

Das separate Add-on **DragonBackpack_Colors_26.3_Addon.zip** enthält 16 farbabhängige 3D-Itemmodelle samt Texturen für DragonBackPacks.

**Testinstallation:** Lege das Add-on als eigenes ZIP in den Ordner `resourcepacks` und aktiviere es **oberhalb** von DragonStuff Resource Pack 26.3.

**Gemeinsame Veröffentlichung:** Kopiere aus dem Add-on die Ordner `assets/dragonstuff/items`, `assets/dragonstuff/models/item` und `assets/dragonstuff/textures/item` in das Haupt-Resource-Pack. Behalte die bestehende `pack.mcmeta` des Hauptpacks bei.

Die Modelle werden vom Plugin nur DragonBackPack-Items mit gültiger Backpack-ID und Tier-Kennung zugewiesen. Normale Shulker-Boxen und die Vanilla-Blockmodelle werden nicht überschrieben. Das neue 3D-Modell wird in dieser Version für das Item in Inventar, Hand und als Item-Drop verwendet; ein platzierter Rucksack bleibt vorerst ein normal dargestellter Shulker-Block.

Der Entwurf und die Farbtexturen stammen von Jax. Die Nutzung und Anpassung für DragonStuff wurden vom Ersteller im Discord-Gespräch am 9. November 2026 gestattet. Details und Projektlink stehen in `CREDITS_BACKPACKS.txt`.

## Fehlerbehebung

- **Vanilla-Textur statt DragonStuff-Textur:** Prüfe, ob das richtige Pack aktiviert ist und ältere Versionen deaktiviert sind.
- **Rüstung wird falsch angezeigt:** Prüfe, ob Plugin und Resource Pack zusammenpassen.
- **Änderungen erscheinen nicht:** Lade die Ressourcen in Minecraft mit **F3 + T** neu.
- **Dragon-Trim erscheint als Netherstern:** Das Item muss vom Plugin mit dem passenden Item-Modell versehen werden.
